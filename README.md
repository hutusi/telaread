# Tela feedback

[English](#english) · [中文](#中文)

## English

[Tela](https://telaread.com) is a multilingual reader for independent blogs: subscribe to blogs,
read each post beside a translation into Chinese, English or French, and see what other readers
recommend. This repository is where you tell us what is wrong with it and what it should do next.

### What to file here

- **Bugs**: something broken, wrong or confusing.
- **Ideas**: a feature you want, or a change to one that exists.
- **Translations**: a post whose translation is wrong, missing or garbled.
- **Blogs**: a blog Tela should carry, or one that won't load.
- **Questions**: how something works.

[Open an issue](https://github.com/hutusi/telaread/issues/new/choose) and pick the form that fits.
Write in any language you like.

### Before you file

- **Search first.** If someone has already reported it, add a 👍 to their issue rather than a
  "+1" comment, and comment only if you have something new: another way to reproduce it, or a
  page where it happens.
- **This repository is public.** Never post your email address, a sign-in code, a password or
  anything from your account you would not show everyone. For anything about your account, your
  data or your privacy, write to [me@hutu.si](mailto:me@hutu.si) instead.
- **Security problems** go to [me@hutu.si](mailto:me@hutu.si) privately, never in an issue. See
  [SECURITY.md](SECURITY.md).
- **Writers**: if Tela carries your blog and you want it changed or taken out, write to
  [me@hutu.si](mailto:me@hutu.si). To claim your blog, see
  [telaread.com/writers](https://telaread.com/writers).

### What happens next

Tela is run by one person, so replies can take a few days. Each issue gets labels: `confirmed`
once it is reproduced, `needs info` when more detail is needed (an issue that stays silent for two
weeks after that is closed, and can be reopened any time), and an `area: …` label for the part of
Tela it is about. An issue is closed when the fix is live on telaread.com, or with a reason when it
won't be done.

## 中文

[Tela](https://telaread.com) 是一个多语言的独立博客阅读器：订阅博客，把每篇文章和它的中文、英文或法文译文对照阅读，看看其他读者推荐了什么。如果你发现 Tela 有问题，或者希望它增加什么功能，请在这里告诉我们。

### 可以反馈什么

- **问题（Bug）**：坏了、不对或者让人困惑的地方。
- **建议**：想要的新功能，或者对现有功能的改进。
- **翻译**：某篇文章的译文有错、缺失或乱码。
- **博客**：希望 Tela 收录的博客，或者无法加载的博客。
- **疑问**：某个功能怎么用。

[新建 issue](https://github.com/hutusi/telaread/issues/new/choose)，选一个合适的表单即可。用什么语言写都可以。

### 提交之前

- **先搜索一下。** 如果已经有人报告过，请在那个 issue 上点 👍，不用回复“+1”；有新信息再评论，比如另一种复现方式，或者出问题的另一个页面。
- **这个仓库是公开的。** 不要贴出你的邮箱、登录验证码、密码，或者任何你不想让所有人看到的账户信息。账户、数据或隐私相关的问题，请写信到 [me@hutu.si](mailto:me@hutu.si)。
- **安全问题**请私下发邮件到 [me@hutu.si](mailto:me@hutu.si)，不要提 issue。详见 [SECURITY.md](SECURITY.md)。
- **博主**：如果 Tela 收录了你的博客，而你想修改或移除，请写信到 [me@hutu.si](mailto:me@hutu.si)。认领博客请看 [telaread.com/writers](https://telaread.com/writers)。

### 提交之后

Tela 由一个人维护，回复可能要几天。每个 issue 会打上标签：复现之后标 `confirmed`；需要更多信息时标 `needs info`（之后两周没有回音的会被关闭，随时可以重新打开）；再加一个 `area: …` 标签，说明它属于 Tela 的哪个部分。修复上线到 telaread.com 后 issue 会关闭；不打算做的，也会说明原因再关闭。
