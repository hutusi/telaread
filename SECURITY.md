# Security

Please report security problems privately, by email to [me@hutu.si](mailto:me@hutu.si), and never
in a public issue. Say what you found, how to reproduce it, and what it lets someone do. You will
get a reply, and credit in the fix if you want it.

In scope: [telaread.com](https://telaread.com) and the API for apps at `api.telaread.com`. Please
test only against your own account, and do not read, change or delete anyone else's data, or run
tests that degrade the service for others.

## 安全问题

请把安全问题私下发邮件到 [me@hutu.si](mailto:me@hutu.si)，不要提公开的 issue。请说明你发现了什么、如何复现，以及它会让别人能做到什么。我会回复你；如果你愿意，修复时会注明你的贡献。

范围：[telaread.com](https://telaread.com) 和面向应用的 API `api.telaread.com`。请只用你自己的账户测试，不要读取、修改或删除他人的数据，也不要进行会影响其他人使用的测试。
